# Histogram by Lean Excel

Histogram with bins that match Microsoft Excel, normal curve, spec limits, Pp and Ppk, and cross-filtering.

Version 1.1.2.0. Support: https://www.leanexcel.com/support/histogram-by-lean-excel

## Build

```bash
npm install -g powerbi-visuals-tools@7.2.1   # the exact version this package was built with
npm install
npm run eslint
npm run package   # output: dist/*.pbiviz
```

This repository contains the source of exactly one Power BI visual. The `certification` branch matches the package submitted to Microsoft Partner Center.
